# Мои идеи проектов

Красивый мини-сайт для записи идей проектов, которые приходят в голову по дороге. Все задачи сохраняются в браузере через `localStorage`, так что работает без сервера и идеально подходит для GitHub Pages.

## Функции

- Добавлять новые идеи
- Отмечать выполненные галочкой
- Фильтровать: все / активные / выполненные
- Удалять идеи
- Сохранение в браузере (localStorage)
- Адаптивный дизайн с плавными анимациями

## Как запустить локально

Просто открой `index.html` в браузере. Для точного отображения шрифтов лучше через локальный сервер:

```bash
python3 -m http.server 8000
```

Потом открой http://localhost:8000

## Как задеплоить на GitHub Pages

1. Перейди по ссылке и создай новый репозиторий:
   https://github.com/new

2. Загрузи файлы `index.html`, `styles.css`, `app.js` и `README.md` в корень репозитория.

3. Открой вкладку **Settings** → **Pages** в репозитории.

4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main** / **master**
   - Folder: **/ (root)**

5. Нажми **Save**. Через минуту сайт будет доступен по адресу:
   `https://ТВОЙ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`
