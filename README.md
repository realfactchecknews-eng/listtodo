# Мои идеи проектов

Красивый мини-сайт для записи идей проектов, которые приходят в голову по дороге. Все задачи сохраняются в браузере через `localStorage`, так что работает без сервера и идеально подходит для GitHub Pages.

## Функции

- Добавлять новые идеи
- Отмечать выполненные галочкой
- Фильтровать: все / активные / выполненные
- Удалять идеи
- Сохранение в браузере (localStorage)
- Синхронизация между устройствами через Firebase Realtime Database
- Адаптивный дизайн с плавными анимациями

## Как запустить локально

Просто открой `index.html` в браузере. Для точного отображения шрифтов лучше через локальный сервер:

```bash
python3 -m http.server 8000
```

Потом открой http://localhost:8000

## Как задеплоить на GitHub Pages

1. Перейди по ссылке и создай новый репозиторий:
   https://github.com/new

2. Загрузи файлы `index.html`, `styles.css`, `app.js` и `README.md` в корень репозитория.

3. Открой вкладку **Settings** → **Pages** в репозитории.

4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main** / **master**
   - Folder: **/ (root)**

5. Нажми **Save**. Через минуту сайт будет доступен по адресу:
   `https://ТВОЙ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## Синхронизация между устройствами

Чтобы задачи были общими на ПК и телефоне, используется Firebase Realtime Database:

1. Зайди на https://console.firebase.google.com/ и создай проект.
2. Создай **Realtime Database** (регион можно оставить по умолчанию).
3. В правилах базы временно разреши чтение и запись:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
   > Это подходит для личного использования. Для публичного проекта используй аутентификацию.
4. Скопируй URL базы данных, он выглядит так:
   `https://listtodo-abc123-default-rtdb.firebaseio.com/`
5. Вставь URL в блок «Синхронизация» на сайте и нажми подключить.
6. Тот же URL вставь на другом устройстве — задачи будут общими.

> **Важно:** ссылка на базу должна заканчиваться на `.firebaseio.com/`, без `tasks.json`.

### Если не работает синхронизация

- Открой консоль браузера (F12 → Console) и посмотри текст ошибки.
- Убедись, что в правилах базы стоит `.read: true` и `.write: true`.
- Проверь, что URL вставлен полностью, без лишних символов.
- Убедись, что на обоих устройствах вставлен один и тот же URL.
